# 🩺 Diabetes Prediction & Risk Analysis

## 📌 Overview
This project presents an AI-powered system for predicting diabetes risk using Machine Learning techniques. It covers the complete workflow, including data preprocessing, exploratory data analysis (EDA), model training, evaluation, and deployment preparation.

## ✨ Features
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Machine Learning Model Training
- Model Evaluation
- Diabetes Risk Prediction
- Deployment Preparation

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📂 Repository Structure
- Graduation_notebook.ipynb
- Deployment_Model.ipynb
- diabetes.csv (if available)

## 🎯 Project Goal
The goal of this project is to develop a reliable machine learning model that predicts diabetes risk and demonstrates the complete data science workflow from raw data to deployment.
